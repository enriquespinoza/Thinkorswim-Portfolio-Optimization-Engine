# Local Source Materials

This directory documents the convention for locally retained third-party source files.

Do not commit copyrighted or access-controlled source documents here unless redistribution rights are clear.

Private local copies should be stored under:

```text
docs/source_materials/private/
```

That path is gitignored.

For the Schwab Trader API source copies used during development, see:

- [../sources/SCHWAB_PRIMARY_SOURCES.md](../sources/SCHWAB_PRIMARY_SOURCES.md)

The public manifest records titles, capture dates, file sizes, SHA-256 hashes, relevant endpoints, provenance, and the official provider location without redistributing the underlying PDFs.
